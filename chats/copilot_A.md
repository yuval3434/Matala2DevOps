## 4. בדיקות ל-`add`

**Claude:** הרחיב את `testAdd` הקיימת והוסיף: `testAddWithZero`, `testAddNegatives`, `testAddIsCommutative`, `testAddOverflowWrapsAround` (`Integer.MAX_VALUE + 1` גולש ל-`Integer.MIN_VALUE`). 5 בדיקות עוברות.

**יובל:** מה הפונקציות שהחבר שלי עושה?

**Claude:** הסביר כל אחת מ-6 הפונקציות ומקרי הקצה שלהן:

| פונקציה | מה עושה | מקרי קצה |
|---|---|---|
| `fibonacciUpTo(n)` | רשימת פיבונאצ'י עד n כולל | `n=0`, `n=1`, שלילי → חריגה |
| `charFrequency(s)` | ספירת מופעים של כל תו | מחרוזת ריקה, רווחים, רגישות לאותיות גדולות |
| `isAnagram(s1, s2)` | אותן אותיות, בלי רווחים ובלי רגישות לגודל | אורכים שונים, אותיות חוזרות, מחרוזות ריקות |
| `average(arr)` | ממוצע כ-`double` | מערך ריק → חריגה, שליליים, השוואה עם delta |
| `filterEvens(list)` | רק הזוגיים | רשימה ריקה, 0, זוגיים שליליים |
| `mostCommonWord(text)` | המילה הנפוצה ביותר | רגישות לגודל, פיסוק, טקסט ריק מחזיר `""`, תיקו לא דטרמיניסטי |


## 5. בדיקות ל-`isPrime`

**יובל:** טוב עשיתי פוש

**Claude:** כתב בדיקות שמכסות את כל הנתיבים:
- `n < 2` (1, 0, שלילי, `Integer.MIN_VALUE`) → false
- 2 ו-3 – הלולאה לא רצה
- זוגיים – נכשלים ב-`i = 2`
- ריבועים של ראשוניים (9, 25, 49) – בודק שהתנאי `i <= sqrt(n)` כולל את השורש
- אי-זוגיים פריקים (15, 91)
- ראשוניים גדולים (97, 7919, `Integer.MAX_VALUE`)

11 בדיקות עוברות.
